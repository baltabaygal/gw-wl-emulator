# plots/ — Generated figures

Output figures (PNG/PDF) from the scripts in `scripts/`, `ml/`, and `python/`. This is a
generated-output folder — files here are reproducible by rerunning their source scripts.

- `figures/` — figures intended for reuse / publication.
- Everything else in the top level is script output; safe to regenerate.

For the curated, provenance-tracked **paper submission** figures, use `paper_prod/`
instead (each figure there has a metadata JSON recording script, commit, and seed).
