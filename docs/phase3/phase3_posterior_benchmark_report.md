# Phase 3 Posterior Benchmark Report

## 1. Motivation

Phase 3 is the posterior-level validation gate for replacing simulator likelihood evaluations with the Conditional NSF in weak-lensing cosmological inference.

## 2. Phase 2C Recap

Phase 2C established the NSF as the production candidate after PDF, tail, likelihood-surface, and parameter-recovery validation. The remaining stress regime is `z = 0.5`, where the lensing PDF is narrow.

## 3. Mock Catalog Design

Mock catalogs are generated by `ml/generate_mock_catalogs.py` for single-redshift, mixed-uniform, and optional high-redshift-weighted regimes. Metadata preserves true cosmology, simulator commit, seed, and catalog hash.

## 4. Posterior Grid Methodology

`ml/run_phase3_posterior_grid.py` evaluates deterministic grids instead of relying on simulator MCMC. Both simulator and NSF use identical flat priors.

## 5. Simulator vs NSF Posterior Comparisons

The first real smoke comparison was run on a central mixed catalog with `N=1000`, a 2D `(OmegaM, sigma8)` grid at resolution 12, and `h` fixed to the true value.

The run completed without NaNs, cache mismatches, or serialization failures, but posterior agreement failed:

- Posterior JSD: 0.607845
- Total variation distance: 0.947312
- 68% credible-region overlap: 0.000
- 95% credible-region overlap: 0.167
- Normalized shifts: `OmegaM = 8.027`, `sigma8 = 7.788`

The NSF posterior shifted toward low `OmegaM` and high `sigma8` relative to the simulator reference.

## 6. Coverage Results

Coverage was deferred because the simulator-vs-NSF smoke gate failed. Running NSF-only coverage before resolving the simulator reference mismatch would not answer the simulator-replacement question.

## 7. Low-Redshift Stress Test

Low-redshift catalogs at `z = 0.5` are treated as a separate catalog class so any posterior-level failure can be isolated from mixed and high-redshift performance.

## 8. Runtime Benchmark

The executed smoke grid took 235.15 s for the simulator and 0.426 s for the NSF on the same catalog and grid.

The lightweight runtime benchmark reported projected grid speedups above 2700x for the tested small grid configuration, with a single-likelihood speedup of 27.72x.

## 9. QA and Reproducibility

Phase 3 outputs are metadata-hashed, cache-safe, and stored outside Phase 2 artifact paths. Tests cover prior consistency, cache mismatch refusal, posterior normalization, credible interval ordering, and NaN/Inf rejection.

## 10. Final Recommendation

Option B

NSF is close at the Phase 2C likelihood-surface/PDF level, but the first real Phase 3 posterior smoke benchmark fails the posterior-agreement gate.

Failure mode: central mixed-redshift posterior mismatch. The NSF posterior favors lower `OmegaM` and higher `sigma8` than the simulator reference on the same mock catalog. The immediate Phase 3B target should be the likelihood/reference formulation: binned simulator likelihood sharpness, continuous NSF versus binned simulator comparison, redshift mixing, and local grid resolution around the competing modes.
