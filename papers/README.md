# papers/ — Reference literature

Source PDFs and markdown notes for the papers this project builds on. When lifting a
fitting-function number or equation, take it from the PDF here — not from memory.

## Subfolders

- `core/` — primary references, incl. Vaskonen (2026) GW weak-lensing σ₈ (the engine this
  repo reproduces) and Trker (2025) cosmological PDF emulator (ACE).
- `methods/` — ML / statistics methods (mass-map denoising, diffusion reconstruction,
  ML weak-lensing cosmology).
- `context/` — background cosmology papers.
- `misc/` — substructure references (JvdB14, vdB05, Han+16, BMO09, SatGen, CUSP) and
  other unsorted material.

Many PDFs now have a companion `.md` (extracted notes) alongside them.
